Chave do Gemini (IA gratuita)

Usada só no botão "✨ Cadastrar por foto". Cada pessoa cria a sua chave, sem custo e sem cartão.

  1. Abra aistudio.google.com/app/apikey e entre com uma conta Google.
  2. Clique em Criar chave de API e copie a chave (começa com "AIza").
  3. Cole aqui embaixo e toque em Testar e salvar.
Importante: para ser realmente gratuita, a chave precisa ser de um projeto sem cobrança (ao criar, escolha "em um projeto novo"). Se o projeto tiver créditos pré-pagos ou cartão, o Google cobra dele em vez de usar a cota gratuita — e, quando os créditos acabam, a leitura para de funcionar.
A chave fica salva somente neste aparelho/navegador — quem usar este aparelho consegue usá-la. No plano gratuito o Google pode usar o conteúdo enviado (as fotos das embalagens) para melhorar os produtos dele; não envie foto com dados de clientes. Há limite diário de leituras, que o Google define e pode mudar.
